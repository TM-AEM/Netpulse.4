# NetPulse - مراقب استهلاك البيانات لنظام أندرويد (Android Native Network Monitor)

تطبيق أندرويد أصلي (Native Android) مبني باستخدام **Kotlin** و **Jetpack Compose** لمراقبة استهلاك الإنترنت والبيانات بدقة تامة وبأعلى درجات الخصوصية.

## المميزات الرئيسية
- **مصدر موثوق ومباشر (Single Source of Truth):** يعتمد حصرياً على `NetworkStatsManager` من نظام التشغيل أندرويد مباشرة، مما يضمن دقة 100% ومطابقة إعدادات النظام.
- **بدون استهلاك موارد أو خلفية (No Background Battery Drain):** لا توجد خدمات خلفية، ولا تخزين أو قواعد بيانات محلية للاستهلاك، ولا عدادات مكررة.
- **خصوصية مطلقة (Zero Telemetry & 100% Local):** لا يطلب إذن الإنترنت (`android.permission.INTERNET`)، ولا يقوم بإرسال أي بيانات خارج جهازك نهائياً.
- **فصل دقيق للشبكات:** فصل استهلاك الواي فاي (Wi-Fi) عن بيانات الجوال (Mobile Data).
- **إحصائيات تفصيلية:** عرض بيانات التنزيل (Download/RX) والرفع (Upload/TX) والإجمالي، مع حساب النسب المئوية.
- **تخصيص الفترات الزمنية:** دعم كامل لليوم، أمس، آخر 7 أيام، آخر 30 يوماً، هذا الشهر، أو تحديد فترة زمنية مخصصة بكل مرونة.
- **رسم بياني يومي تفاعلي:** تفصيل استهلاك الأيام السابقة برسم بياني أنيق.
- **دعم اللغة العربية والإنجليزية والثيمات:** دعم الوضع الداكن/الفاتح وتغيير وحدات القياس (تلقائي، ميجابايت، جيجابايت).
- **أداة تشخيص ومقارنة دقيقة (Diagnostics Tool):** تدعم فلترة التشخيص حسب نوع الشبكة (Wi-Fi، Mobile، Total)، مع قراءة عدادات الحزم (Packets) الحقيقية من الحزم في نظام أندرويد دون اصطناع قيم غير موجودة، ومقارنة توضيحية بين بيانات `NetworkStatsManager` التاريخية للفترة الزمنية المحددة وبيانات `TrafficStats` اللحظية المرتبطة بالإقلاع الحالي للجهاز.

## سياسة الأمان والتوقيع (Security & Signing Policy)
- لا يتم تضمين أو تتبع أي مفاتيح توقيع (`*.jks` أو `*.keystore`) أو بيانات اعتماد سرية داخل مستودع Git إطلاقاً.
- ملفات التوقيع مستثناة في `.gitignore` ويتم تزويدها خارجياً عبر بيئة البناء أو متغيرات البيئة.
